# Оценка качества вина

Приложение Streamlit для отбора хороших вин в подборку сервиса по подписке. Модель оценивает вероятность экспертной оценки не ниже 7 баллов.

## Окружение

Проверенное окружение комплекта: Python 3.13.2. Точные версии библиотек зафиксированы в `requirements.txt`.

Модель обучается в ноутбуке. Приложение загружает готовый пайплайн и не выполняет повторное обучение. Для другой модели, экспортированной из Colab, версии библиотек должны соответствовать окружению её обучения.

## Файлы

- `app.py` — приложение Streamlit.
- `model.joblib` — обученный пайплайн обработки признаков и классификации.
- `config.json` — порог классификации по умолчанию.
- `test.csv` — тестовая выборка с целевой переменной `target`.
- `requirements.txt` — точные версии зависимостей.
- `README.md` — описание приложения и инструкция запуска.

Все файлы должны находиться в одной папке.

## Запуск на macOS и Linux

Откройте терминал в папке приложения. Используйте Python 3.13.2.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откройте адрес из терминала, обычно `http://localhost:8501`. Терминал должен оставаться открытым. Для остановки нажмите Control + C.

## Запуск на Windows

В командной строке, используя ту же версию Python:

```bat
py -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
